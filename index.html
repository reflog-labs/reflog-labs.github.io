// 01 LOOP

The Contribution Cycle

Four steps. Every one of them can be undone.

01 / STEP
Fork

Copy the upstream repository to your personal namespace without affecting the original codebase.

02 / STEP
Branch

Create an isolated workspace for your changes so main stays untouched and clean.

03 / STEP
Pull Request

Propose changes, receive reviewer feedback, run automated test suites, and iterate cleanly.

04 / STEP
Merge

Integrate verified code into production. History is safely recorded in Git refs forever.
